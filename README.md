# TMDbHelper Sync - MDbList

This optional module owns MDbList API access, credentials, sync, scrobbling,
list directories, actions, ratings, monitored lists, and artwork for TMDbHelper.
It implements provider interface version 4. Shared orchestration and provider
contracts are documented in the
[core provider guide](https://github.com/jurialmunkey/plugin.video.themoviedb.helper/blob/nexus/resources/tmdbhelper/lib/sync/providers/README.md).

## Setup and credentials

Install and enable `script.module.tmdbhelper.sync.mdblist`. Open its settings
from TMDbHelper's MDbList API settings button and enter your personal API key.
The module stores it as `apikey`. Opening settings does not select MDbList as
a history, watchlist, collection, or scrobbling provider; configure those
features separately in TMDbHelper's sync settings.

The module's `migrate_settings()` hook checks core's saved legacy
`mdblist_apikey` whenever the provider loads, including discovery and installation.
It copies the key only if the module has no key, verifies the destination, and
then clears the core value. An existing module key takes precedence. Failed
writes preserve the source for retry. Kodi loads saved values without definitions
as hidden internal string settings, so the old value remains accessible through
`getSetting()` without a core settings declaration.

## Browsing lists

The module registers `mdblist_directory` and its `mdblist_*` list routes.
TMDbHelper remains the plugin URL entry point:

| List | URL |
| --- | --- |
| MDbList root | `plugin://plugin.video.themoviedb.helper/?info=mdblist_directory` |
| Top Lists | `plugin://plugin.video.themoviedb.helper/?info=mdblist_toplists` |
| Your Lists | `plugin://plugin.video.themoviedb.helper/?info=mdblist_yourlists` |
| Liked Lists | `plugin://plugin.video.themoviedb.helper/?info=mdblist_likedlists` |
| Curated Lists | `plugin://plugin.video.themoviedb.helper/?info=mdblist_curatedlists` |
| Official Lists | `plugin://plugin.video.themoviedb.helper/?info=mdblist_officiallists&tmdb_type=movie` |
| Streaming Charts | `plugin://plugin.video.themoviedb.helper/?info=mdblist_streamingcharts&tmdb_type=movie` |
| Search Lists | `plugin://plugin.video.themoviedb.helper/?info=mdblist_searchlists&query=QUERY` |
| List Items | `plugin://plugin.video.themoviedb.helper/?info=mdblist_userlist&list_id=LISTID` |

Official lists and streaming charts also accept `tmdb_type=tv`.
The module owns the API client and rating-response mappings. Skin Shortcuts
sorting uses the mapper's `sortby_info=mdblist_sortby` property; context-menu
sorting uses core's generic `sort_list` command, which resolves the module's
sorting container through the provider registry.

### Saved JSON lists

`mdblist_locallist` reads a local file, network path, `special://` path, or HTTPS
URL. The JSON can be generated by MDbList, another script, or written by hand.
The [example JSON](resources/jsondata/example_mdblist_locallist.json) demonstrates
movies, shows, seasons, and episodes. It is shipped with this module.

Use a double ampersand (`&&`, or `&amp;&amp;` in XML) before the file location:

```text
plugin://plugin.video.themoviedb.helper/?info=mdblist_locallist&&location/of/the/json/file.json
```

To load the installed example:

```text
plugin://plugin.video.themoviedb.helper/?info=mdblist_locallist&&special://home/addons/script.module.tmdbhelper.sync.mdblist/resources/jsondata/example_mdblist_locallist.json
```

## List actions

The module provides the `mdblistuser` item action for adding media to a static
list or removing it from the displayed list. This is independent of selected
sync providers.

List like/unlike actions use the module's existing Kodi script entry point:

```text
RunScript(script.module.tmdbhelper.sync.mdblist,like_list=LISTID)
RunScript(script.module.tmdbhelper.sync.mdblist,like_list=LISTID,delete=true)
```

The mapper builds these commands. `actions/like.py` owns the request, result
dialog, and successful container refresh. The script resolves the provider
through `tmdbhelper_lib.sync.providers.interface.SyncProviderRegistry` before
accessing its API, requiring TMDbHelper 6.21.3 or later. Calling it without
arguments opens provider setup. Core's old `like_mdblist` script route has been
removed.

Watched additions use a concrete invalidator that preserves the history
timestamp for incremental requests; removals invalidate it for a full snapshot.

## Ratings and monitored lists

The module supplies public ratings for movies, shows, seasons, and episodes
through core's ratings supplier interface and its module-owned API client.

Library monitoring uses the module's supplier rather than directory containers.
Saved references retain `__api_mdblist__` as `user_slug` and numeric list IDs as
`list_slug`; no migration of monitoring settings is needed. Display labels remain
`MDbList: <name>`. The module owns API requests, separate movies/shows response
handling, normalization, and incomplete-record filtering. Core owns library
creation and monitoring orchestration.

## Localization and artwork

Module-only UI strings live in `resources/language/`. Their existing IDs and
translations are preserved. `localization.py` resolves these IDs against this
addon and delegates shared strings to TMDbHelper. Module menu items resolve their
own labels, and containers configure translated headings before accessing cached
list properties. The API settings labels use IDs 32000-32002 in this addon.

MDbList icons and type variants live in `resources/icons/mdblist/` and are
selected by `directories/artwork.py`. They are not part of core's icon manifests.
